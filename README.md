# Ejercicios Básicos de Java y POO

Colección de ejercicios prácticos de repaso en Java que abarcan desde estructuras de control y manejo de cadenas y colecciones hasta Programación Orientada a Objetos (POO) y control de excepciones.

---

## Resumen de los ejercicios

* **Ejercicio 1 (`Ejercicio1.java`)**: Estructuras condicionales y bucle del 5 al 30 indicando si cada número es mayor, menor o igual a 15.
* **Ejercicio 2 (`Ejercicio2.java`)**: Manipulación de cadenas de texto (`String`): comprobación de longitud, detección y reemplazo de subcadenas ("hola" por "adiós") y recuento de vocales.
* **Ejercicio 3 (`Ejercicio3.java`)**: Funciones auxiliares y arrays: saludo personalizado, cálculo de media, recorrido con formato de arrays, ordenación alfabética y obtención del valor máximo.
* **Ejercicio 4 (`Ejercicio4.java`)**: Manejo de colecciones con `ArrayList`: búsqueda de elementos, borrado por posición, filtrado de extremos (máximo y mínimo), suma de números positivos y eliminación de duplicados.
* **Ejercicio 5 (`Ejercicio5.java`)**: Clase `Persona`: atributos privados, constructor, getters/setters, métodos para cumplir años (`edad++`), mostrar información y conversión de altura a centímetros.
* **Ejercicio 6 (`Ejercicio6.java`)**: Clase `Producto`: uso de clases envoltorio (`Double`) para permitir valores `null`, conversión a pesetas y manejo de excepciones (`NullPointerException`) con `try-catch`.
* **Ejercicio 7 (`Ejercicio7.java`)**: Clase `Empleado`: inicialización mediante setters, cálculo de salario anual multiplicando por 12 y control de excepciones cuando el salario es `null`.

---

## Ejecución

Cada archivo cuenta con su propio método `main` para probar su funcionamiento. Se pueden ejecutar individualmente desde cualquier IDE o por terminal:

```bash
java "Ejercicios Repaso/src/Ejercicio1.java"
```
